# Drupal Legacy Project

Do not start a new Drupal project with this unless there is some reason why
you cannot use the [recommended project layout](https://github.com/drupal/recommended-project).

For more on the Drupal Legacy Project, see 
[Starting a Site Using Drupal Composer Project Templates > drupal/legacy-project](https://www.drupal.org/docs/develop/using-composer/starting-a-site-using-drupal-composer-project-templates#s-drupallegacy-project).

## Recommended method to install Drupal

- [User Guide: Using Composer to Download and Update Files](https://www.drupal.org/docs/user_guide/en/install-composer.html)
- [Starting a Site Using Drupal Composer Project Templates](https://www.drupal.org/docs/develop/using-composer/starting-a-site-using-drupal-composer-project-templates)
