# Starterkit Theme

# How to use Starterkit
The Starterkit theme is not a theme directly used by Drupal, nor is it a theme
used as a base theme. Starterkit is for **generating new themes** that include
reasonably unopinionated 'starter' templates and styles that eliminate much of
the initial work required to create a theme.

If you're developing a new theme, it's worth seeing if Starterkit will benefit
that process. Consult the [Starterkit documentation on Drupal.org](https://www.drupal.org/docs/core-modules-and-themes/core-themes/starterkit-theme)
for details.
